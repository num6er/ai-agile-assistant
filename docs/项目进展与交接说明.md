## 一、项目是什么

**AI 敏捷开发助手**：输入一份 PRD，自动完成敏捷开发前期的 5 个环节：

```
① 解析功能点 → ② 生成用户故事 → ③ 拆解任务 → ④ 估算工时 → ⑤ 按技能分配给成员
```

技术栈：Python Flask + SQLite + Vue3 + Element Plus + DeepSeek LLM。

## 三、已经修过的 Bug / 改进

1. **openai 库与 httpx 版本冲突**：旧版 openai 调新版 httpx 会报 `unexpected keyword argument 'proxies'`。已将 `openai` 升到 1.51.0 并约束 `httpx<0.28`。
2. **任务分配漏分**：原 Prompt 没强约束，LLM 会漏分部分任务。已在 Prompt 中明确要求每个任务必须分配且成员名必须从给定名单中选。
3. **大量任务时 AI 输出被截断**：任务数超过约 150 个时，LLM 一次性返回的 JSON 超出 `max_tokens` 被截断，导致解析失败。已改为**每 30 个任务分批调用**后合并，150 任务实测通过。
4. **跨批次负载均衡**：分批分配后各批独立，会导致负载倾斜。已改为每批回传当前已分配工时/任务数，让模型跨批次均衡分配（三人技能相同时实测 50/50/50）。
